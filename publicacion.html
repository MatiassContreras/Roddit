Mi primer sitio estático quedó listo, pero el footer no se queda abajo. ¿Qué hago mal?

Estoy armando mi primer sitio estático para la facultad, solo con HTML y CSS. Tengo un header, el contenido principal y un footer con enlaces.

El problema: cuando la página tiene poco texto, el footer queda flotando a mitad de pantalla en lugar de pegarse al borde inferior. Probé con position: absolute y bottom: 0, pero en el celular se superpone con el contenido.

¿Cuál es la forma más simple y prolija de resolverlo?

Edición: gracias por las respuestas, ya lo resolví con flexbox. Dejo el hilo por si le sirve a alguien más.

  1. CA u/ciervoAustral hace 1 h

    Lo más simple: convertí el body en una columna flex y hacé que el main ocupe el espacio sobrante.

    body {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
}

main {
  flex: 1;
}
